# Desktop application

## Language

**Theme preference**: The user's choice of light, dark, or following the system. A missing or unrecognized saved choice means following the system.

**Appearance**: The light or dark appearance currently visible to the user. When the theme preference follows the system, the appearance changes with the system preference.

**Window state**: The platform and fullscreen state of one application window.

**Panel**: An optional left or right area beside the main content. A collapsed panel retains its previous expanded width.
